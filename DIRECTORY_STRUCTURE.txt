📂 DIRECTORY ORGANIZATION

docs/          → All documentation (setup guides, architecture, references)
src/           → Application source code (HTML, JS, Python scripts)
data/          → Data files and operation logs (CSV files)
infrastructure/→ Infrastructure as Code (Pulumi AWS configuration)
.github/       → GitHub Actions workflows (CI/CD automation)

🔧 COMMON OPERATIONS

View documentation:
  $ cat docs/INDEX.md
  $ cat docs/DEPLOYMENT.md

Run data fetchers:
  $ python src/fetch_data.py
  $ python src/fetch_sentiment.py

Check data files:
  $ ls -la data/

Deploy infrastructure:
  $ cd infrastructure
  $ pulumi up
